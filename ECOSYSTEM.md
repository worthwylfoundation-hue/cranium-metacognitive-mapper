# Ecosystem map

`cranium-metacognitive-mapper` is a supporting metacognitive mapping and creative-intelligence surface within the Convertible Cranium ecosystem. It is non-authoritative.

The Mapper can propose cognitive interpretations and package context, but cannot make those interpretations authoritative, issue canonical receipts, or replace the private Kernel authority plane. Kernel references in this repository are descriptive; the exact authority revision should be recorded in a `KERNEL_PIN` before any release claim.
